portfolio.slopeit.com

Site architecture

Cloudflare handles DNS and proxies requests to Amazon CloudFront. CloudFront delivers the static files from Amazon S3. The site is built locally with React, TypeScript and Vite.

Request path

Follow a request that reaches the S3 origin.

  1. Browser

    Requests portfolio.slopeit.com over HTTPS.

  2. Cloudflare

    Resolves the domain and proxies the request to CloudFront.

  3. Amazon CloudFront

    Checks its cache and forwards a cache miss to the origin.

  4. Amazon S3

    Serves the portfolio’s static HTML, styles, scripts and media.

From source to production

The deployment script checks the working tree and AWS credentials before building and publishing.

  1. Build with Vite

    Generate the static site and versioned assets in dist/.

  2. Upload to S3

    Sync versioned assets with long-lived cache headers and other static files with a shorter cache. Upload index.html last so it only references assets already in S3.

  3. Invalidate CloudFront

    Request a CloudFront invalidation so the CDN fetches the new build.
