How the site is delivered

Cloudflare publishes the DNS record and serves as the first CDN cache in the request path.

DNS resolution

300 s TTL

  1. Recursive resolver

    Looks up IPv4 and IPv6 addresses for portfolio.slopeit.com.

  2. Cloudflare authoritative DNS

    Publishes the slopeit.com zone across its global DNS network.

  3. Cloudflare edge IPs

    The proxied record returns Cloudflare anycast addresses. The resolver caches them for their DNS TTL.

HTTPS and CDN caches

Preview a request that misses both caches and reaches S3.

  1. Browser

    Uses a resolved edge IP to connect to portfolio.slopeit.com over HTTPS.

  2. Cloudflare CDN

    Checks the first edge cache. A miss or an uncached request is forwarded to CloudFront.

    Cache hit → browser

  3. Amazon CloudFront

    Checks the second edge cache. On a miss, it fetches the file from S3.

    Cache hit → Cloudflare

  4. Amazon S3 origin

    Stores the published HTML, scripts and media. Files return through the CDN layers.

After a deploy GitHub Actions invalidates CloudFront. Cloudflare applies its own cache rules. Versioned assets use new URLs when their content changes.
