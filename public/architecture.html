Architecture — portfolio.slopeit.com

A static React single-page app, served from Amazon S3 through AWS CloudFront, with Cloudflare handling DNS and edge in front. Deployed manually from the developer machine — a build, an S3 sync, and a cache invalidation.

Build & deploy — how updates ship

Develop & version

Edit the app on the Mac (React 19 + TypeScript). Push source to GitHub for versioning.

git push origin main # → github.com/croguerrero/personalweb

Build with Vite

Produce the static bundle into dist/ (HTML, hashed JS, assets, CV PDF).

npm run build # vite build → dist/

Sync to S3

Upload the build to the origin bucket. --delete prunes stale files; perfil2.png is preserved.

aws s3 sync dist/ s3://slopeit-•••••••-prod/ --delete --exclude "perfil2.png"

Invalidate the CDN

Purge cached objects so visitors get the new version instead of a stale copy.

aws cloudfront create-invalidation --distribution-id E•••••••••6P --paths "/*"

Notes & caveats

Topology Two CDNs in series. Responses carry both server: cloudflare and via: CloudFront — Cloudflare proxies in front of CloudFront, which fronts S3.
Dead path The gh-pages GitHub Action is unused. A workflow deploys to a gh-pages branch, but the live site is served from S3 — pushing to git never updates production. Deploys are the manual AWS steps above.
Perf Tailwind loads at runtime via CDN. The browser compiles CSS on each visit, which delays first paint. Moving Tailwind to the Vite build would remove the wait.
